01.01 — RELATIONAL DBMS & REAL-TIME COORDINATION

Emergency 999 Dispatch System

Real-Time Incident Reporting, Automated Nearest-Unit Routing & High-Concurrency DBMS

A mission-critical emergency management platform built to coordinate Bangladesh's national incident response. Allows citizens to log real-time emergencies on dynamic maps, automatically calculating nearest active units while preventing race conditions through robust database transaction locks.

  • Engineered an 8-table relational schema with strict role-based access for Citizens, Unit Commanders, and Regional Operators.
  • Integrated Haversine geospatial proximity routing algorithms and 5 InnoDB MySQL triggers to guarantee atomicity during simultaneous dispatches.
  • Constructed live Leaflet.js interactive maps with sub-second polling updates and incident status transitions.
